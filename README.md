# 🍕 SliceCraft — Pizza Builder
A modern, interactive pizza ordering web app built with **React** and **Vite**. Users can build their own custom pizza, browse signature options, and experience a beautifully designed café-style interface.
## ✨ Features
- 🛠️ **Custom Pizza Builder** — Choose your base, sauce, toppings, and size
- 🍕 **Signature Pizzas** — Browse pre-designed specialty pizzas
- 📱 **Fully Responsive** — Works seamlessly on mobile, tablet, and desktop
- ⚡ **Fast & Lightweight** — Powered by Vite for blazing fast performance
- 🎨 **Modern UI** — Smooth animations and a premium design
## 🛠️ Tech Stack
| Technology | Purpose |
|---|---|
| React 19 | UI Framework |
| Vite | Build Tool & Dev Server |
| CSS3 | Styling & Animations |
## 🚀 Getting Started
### Prerequisites
- Node.js (v18 or higher)
- npm
### Installation
```bash
# Clone the repository
git clone https://github.com/Mujjamil/PizzaBuilder.git
# Navigate to project folder
cd PizzaBuilder
# Install dependencies
npm install
# Start development server
npm run dev
The app will be running at http://localhost:5173

📦 Build for Production
bash
npm run build
Output will be in the dist/ folder.
