# 🍕 Cafe Pizza — Premium Pizza Builder & Ordering System

A high-end, interactive pizza ordering web application built for a seamless culinary experience. **Cafe Pizza** allows users to craft their perfect pizza with a real-time customizer, explore gourmet signature recipes, and manage orders through an integrated admin dashboard.

---

## 🚀 Key Features

- 🛠️ **Real-time Pizza Builder** — Interactive UI to customize base, sauce, crust, and a vast array of premium toppings.
- 🍕 **Signature Collection** — Explore a curated menu of specialty pizzas with instant "Add to Cart" functionality.
- 🛒 **Dynamic Cart & Checkout** — Smooth sliding cart drawer with real-time price calculation and a secure order placement modal.
- 🛡️ **Admin Control Panel** — Dedicated dashboard for managing active orders, updating status, and tracking sales performance.
- ⚡ **Lightning Fast Performance** — Built on **Vite** for near-instant load times and a fluid user interface.
- 📱 **Fully Responsive** — Sophisticated mobile-first design that looks stunning on every device.
- 🔥 **Live Backend** — Powered by **Firebase** for reliable data storage and real-time order synchronization.

## 📦 Getting Started

### Prerequisites
- **Node.js**: `v18+`
- **npm**: `v9+`

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mujjamil/PizzaBuilder.git
   cd PizzaBuilder
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Launch Development Server**
   ```bash
   npm run dev
   ```
   *The app will be available at `http://localhost:5173`.*
